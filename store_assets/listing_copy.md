## Notes on the "reader app" compliance pattern
Since subscriptions are sold on the web (not via Apple/Google IAP), the listing copy above is written to disclose pricing clearly without including a "Subscribe" button inside the app — the app's in-app subscribe screen already redirects users to powerfulnotes.com per the compliance work done earlier. Keep this disclosure language in the description so pricing isn't a surprise to reviewers or users.
